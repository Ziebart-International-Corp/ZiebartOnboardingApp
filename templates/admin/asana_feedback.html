Setup checklist

  1. In Asana, create a personal access token (My Settings → Apps → Personal access tokens) or a service account token (Enterprise).
  2. Set ASANA_ACCESS_TOKEN in .env to that token.
  3. Set ASANA_FEEDBACK_PROJECT_GID in .env{% if project_gid %} (currently {{ project_gid }}){% else %} — not set yet{% endif %}.
  4. Create three sections in that project (Comments, Issues, Improvements) and set their list GIDs in .env:
    • ASANA_SECTION_GID_COMMENT{% if section_gid_comment %} — {{ section_gid_comment }}{% else %} — not set{% endif %}
    • ASANA_SECTION_GID_ISSUE{% if section_gid_issue %} — {{ section_gid_issue }}{% else %} — not set{% endif %}
    • ASANA_SECTION_GID_SUGGESTION{% if section_gid_suggestion %} — {{ section_gid_suggestion }}{% else %} — not set{% endif %} (maps to “Suggest an improvement”)
    GID is the number in the section URL: .../list/1234567890
  5. Optional: set ASANA_FEEDBACK_ASSIGNEE_GID so every feedback task is assigned automatically{% if assignee_gid %} (currently {{ assignee_gid }}){% endif %}.
  6. Ensure the token’s user/service account has access to that project.
