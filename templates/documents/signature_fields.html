Users draw or apply a saved signature image on this field.

Use the same group name on every box in the set (Single, Married, etc.). The user can mark only one with an X.

All typed fields are required. Checkbox fields require one selection per group.

How to add a field:
1. Select field type above (Signature or Typed Field)
2. Switch to the corresponding mode using the button above the document
3. Click and hold at the top-left corner where you want the field
4. Drag to the bottom-right corner to set the size
5. Release to create the field
6. You can then drag the new field to move it, or drag the corner handles to resize it
7. To move an existing field: switch to Select/Edit, then drag the blue/yellow box on the PDF
